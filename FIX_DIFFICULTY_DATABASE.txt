Option B: Quick fix - Run these queries in Supabase SQL Editor:

-- First, check your Difficulty IDs:
SELECT * FROM "Difficulties";

-- You should see:
-- id | name
-- 1  | Beginner
-- 2  | Intermediate
-- 3  | Proficient

-- Then, assign difficulties to your activities:

-- Set "Identification" to Beginner
UPDATE activities 
SET difficulty_id = 1 
WHERE title ILIKE '%identification%' 
  AND difficulty_id IS NULL;

-- Set "Colors" to Beginner
UPDATE activities 
SET difficulty_id = 1 
WHERE title ILIKE '%color%' 
  AND difficulty_id IS NULL;

-- Set "Matching" to Intermediate
UPDATE activities 
SET difficulty_id = 2 
WHERE title ILIKE '%matching%' 
  AND difficulty_id IS NULL;

-- Set all other Academic activities to Beginner by default
UPDATE activities 
SET difficulty_id = 1 
WHERE category_id IN (
  SELECT id FROM "Categories" 
  WHERE category_name ILIKE '%academic%'
)
AND difficulty_id IS NULL;

-- IMPORTANT: Social/Daily Life activities should keep NULL!

═══════════════════════════════════════════════════════════════════
  UNDERSTANDING THE SYSTEM
═══════════════════════════════════════════════════════════════════

HOW DIFFICULTY WORKS:

1. ACTIVITIES TABLE:
   - Has difficulty_id column (foreign key to Difficulties table)
   - Academic activities MUST have difficulty_id (1, 2, or 3)
   - Social/Daily Life activities have difficulty_id = NULL

2. DIFFICULTIES TABLE:
   id | name
   1  | Beginner      → Green badge  🟢
   2  | Intermediate  → Yellow badge 🟡
   3  | Proficient    → Red badge    🔴

3. WHEN STUDENT PLAYS:
   - Progress saved to user_activity_progress with activity_id
   - Code looks up activity → gets difficulty_id → gets difficulty name
   - Displays that difficulty level in Recent Activities
